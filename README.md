# 🚀 Dhanushka | AI & Web Developer Portfolio

Welcome to my professional portfolio! This is a high-end, responsive web application built to showcase my journey as an IT Undergraduate at ITUM, focusing on Artificial Intelligence and Modern Web Engineering.

![Portfolio Preview](https://your-live-link-here.com/preview.png) ## ✨ Features

- 💎 **Glassmorphic UI:** A modern, sleek design with glass-like components and smooth animations.
- ⚡ **Dynamic Projects:** Project data is fetched in real-time from a **Supabase** database.
- 🤖 **AI Roadmap:** A visual strategic vision of my AI learning journey from foundations to LLMs.
- 📱 **Fully Responsive:** Optimized for all screen sizes, from mobile phones to ultra-wide monitors.
- 📧 **Direct Contact:** Integrated contact form connected to Supabase and a direct WhatsApp call-to-action.
- 🛠️ **Freelance Ready:** Quick links to Upwork and Fiverr profiles for professional collaborations.

## 🛠️ Tech Stack

- **Frontend:** [React.js](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
- **Backend/Database:** [Supabase](https://supabase.com/)
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Dhanuwa856/modern-react-portfolio.git](https://github.com/Dhanuwa856/modern-react-portfolio.git)
   cd modern-react-portfolio
2. **Install dependencies:**
      ```bash
      npm install
3. **Set up Environment Variables**: Create a .env file in the root directory and add your Supabase credentials:      
   ```bash
   VITE_SUPABASE_URL=your_supabase_project_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
4. **Run the development server:**
   ```bash
   npm run dev
